## D-582 · Each agent runs on the model and effort its work needs
**Date:** 2026-11-17 · **Status:** current · **Topics:** agents
**Context:** Every agent inherited the session's model (Opus at low effort): the owner's plan quota went the same way to triaging an email as to designing a game idea. The owner chose impact over cost, so a cheaper model is used only where the work is checked by rules and a miss is caught.
**Decision:** The model and effort live in each agent's frontmatter (`model:`, `effort:`). Judgment agents stay on Opus with the effort their work needs: ideas high; processes and ci-health medium; feedback and usability low. Agents whose work a program or a reviewer checks move to Sonnet: documentation (its output is gated by `document.mjs check` and `readme.py check`), player (it only reports), contributions (already). Support runs on Haiku (it only sorts emails, D-318). `agents-models.test.mjs` fails an agent without both fields.
**Why:** Effort where judgment pays; the quota saved on mechanical work buys a higher effort where it matters. Quality first: an agent moves back to Opus as soon as it misses something its review catches.
**Consequences:** The ci-health agent's weekly cost check reports what each agent spends and any miss by a Sonnet agent; two misses move it back to Opus in that round's PR. The processes round's own headless session (`processes-round`) is the main thread, not a subagent: it runs on the owner's default (Opus, low) and the agents it launches take their own frontmatter.
