## D-590 · Active browsers by game: the random id goes with the game a browser starts, and every WBR games metric says started or finished
**Date:** 2026-11-19 · **Status:** current · **Relation:** amends D-349 (its id carried no game) · **Topics:** panel
**Context:** The owner asked the WBR for weekly active users by game. D-349's random browser id went with nothing ("no game, no page"), so the panel could count browsers overall but not how many distinct ones played each game. The owner asked for an estimate now and for the real count to start measuring the same day, for every player (not through the lab).
**Decision:** when a browser finishes a game (`trackFinish`, and a room's end in `noteWinner`) it writes `juegosPt/<pacific day>/<game>/<id>` = 1, once per game and Pacific day per browser (`gameActiveChange` in `stats.js`); the owner asked that it count games finished, not started, with the same random id as `activos/` and nothing else: no name, no IP, never joined with rooms, Cups, rankings or feedback. The rules accept only 1 under a game key and a 10-character id. The panel moves it to its Pacific day as `jugadores/` and the WBR's "Weekly active users by game" counts distinct ids that finished each game per week (a month: the average of its full weeks). Weeks before the counter covered them show an estimate marked `~`: the browsers that started a game that week (level 2 in `activos/`) split by each game's share of the games finished. /privacy/ says the random number also counts which games are played. **Every games metric in the WBR (panel and the Sunday email) says whether it counts games started or games finished**; "games played" is not a definition (the owner, 2026-11-19).
**Why:** Which games keep people is a different question from which games are played most: one fan can finish fifty games. The id already existed and only says "the same browser as yesterday"; adding the game says nothing more about the person.
**Alternatives discarded:** only the estimate (it reads low, since one browser plays several games, and cannot be checked); a separate id per game (more to store, the same privacy); the lab first (the owner wanted the data to start today).
**Consequences:** The real count starts on 2026-11-19 (Pacific); full weeks are real from Sunday 2026-11-22. A Cup game counts under the game's own id when the Cup page sends it, else under the Cup. Someone who clears their data counts as new, as in D-349.
