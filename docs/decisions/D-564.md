## D-564 · La Copa: a notification when someone comments on your row, and notifications checked every 5 minutes by a relay on GitHub
**Date:** 2026-11-16 · **Status:** amended by D-565, D-574 · **Relation:** amends D-224 · **Topics:** cup, pwa
**Context:** With comments on the cup's table (D-562) launched, the owner asked whether a player should be told when someone comments on their row, and agreed (2026-11-16): grouped, the name but not the text, its own switch, behind a flag, never at night. They wanted checks every 5–10 minutes, not 15; then it turned out the 15-minute cron of D-224 really ran every 4–10 hours. The owner wants it all on GitHub ("todo lo relacionado a la performance del sitio debiese manejarlo GitHub"), not the Mac mini, and Cloudflare kept only for the email.
**Decision:**
- **The notification** (`tools/push/talk.mjs`), behind the flag `cup-talk-push`: «💬 Bea comentó tu resultado», or grouped («2 comentarios nuevos en tu fila, de Bea y Car»); only comments by others, not hidden, from the last 24 h and after the phone turned notifications on; each comment once (`charla:<day>:<author>` in pushEnviados, an edit does not notify again); never at night (the cup's 8–22 h); at most one every 30 minutes per cup and phone; it does not use up the cup's 2 a day. A switch «Comentarios» in ⚙️ Avisos (`pushCopa/…/charla`): before launching, only who turned it on; once launched, everyone with the cup's notifications unless turned off.
- **A relay on GitHub:** notifications.yml runs hourly; a scheduled run checks, then again every 5 minutes for ~5h40m; the concurrency group queues the next run behind it, so one is always up even when GitHub drops starts. A manual run checks once. The public repo's minutes are free.
**Why:** A comment is worth knowing about soon, but not at the cost of the night or the cup's own reminders. GitHub's cron cannot be trusted for frequency; a long-running job can.
**Consequences:** Every notification (the cup's, Uno al día's) now comes within ~5 minutes of being due. A run that dies is replaced within the hour. Launching it for everyone is flipping `flags/cup-talk-push` in /labs/.
