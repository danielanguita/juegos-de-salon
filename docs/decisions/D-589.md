## D-589 · No e2e script depends on the real date
**Date:** 2026-11-19 · **Status:** current · **Relation:** extends D-518 (the same failure gets a mechanism) and D-405 (relative dates in the Uno al día scripts) · **Topics:** tests
**Context:** On 2026-11-19 (UTC midnight), the day's Uno al día cover (Generala) turned every PR red in `landing-fold.mjs`, which measured only the real day's game ([#1624](https://github.com/ellokojavi/juegos-de-salon/pull/1624), fixed for that script in [#1628](https://github.com/ellokojavi/juegos-de-salon/pull/1628)). Other scripts opened pages that change with the date on the real clock: the home page's ✨ New chip and row exist only in a game's first week (`home/popular.mjs`, `home/search.mjs` and `home/carousels.mjs` assert the row fits, or count the rows), La Copa's create screen shows a ✨ New style chip, `/today/` changes its month and calendar, and Halloween dresses the home page and `/records/` without `?test`.
**Decision:** (1) A script that opens a page whose content follows today (the home page, `/today/` or a `?today` link, `/records/`, La Copa's create screen; the shared helpers that open the `paths.mjs` catalog count as opening them all) pins that page's clock: `launch({ …, clock: true })` in `tools/e2e/cdp.mjs` moves every page to noon of `E2E_DAY` (2026-11-18: mid-month, no season, three games carrying ✨ New, the busiest rows) and keeps it running; a script may pass another day, or install its own clock as the Uno al día scripts do. (2) `tools/e2e/real-date.test.mjs` fails a script that opens such a page on the real clock. A script meant to follow the real clock (Node and the page compare times, a service worker or Firebase's server keeps the real one, or it opens the home page only to clear storage) is listed in its `REAL_CLOCK` with the reason; an entry that no longer applies fails. (3) `E2E_DAY` is moved only on purpose, in a PR of its own, never derived from the real date.
**Why:** a test that passes on Tuesday and fails on Wednesday with nothing changed costs a session a chase and every open PR a red run. A fixed day keeps the most crowded state (three new games) tested every run, where the real date tested it only some weeks.
**Consequences:** the home, `/today/`, La Copa create and catalog scripts (`languages-common.mjs`, `look.mjs`) run on 2026-11-18; `landing-fold.mjs` looks for each Uno al día game's day from `E2E_DAY` on. A game launched after `E2E_DAY` does not wear ✨ New in these scripts; a script that checks a new game's label pins its own day.
