## D-559 · Every score a game records has its tab in Rankings, checked by a test
**Date:** 2026-11-15 · **Status:** current · **Relation:** amends D-212 (which games record a ranking) · **Topics:** rankings, tests
**Context:** ¡Al toque! launched on 2026-11-14 recording each run to its `microgames` table, but Rankings (`/records/`) built its tabs from SUELTOS plus a hand-written list (`toque-y-fama`, `ahorcado`, `generala`), so the table existed and nobody could see it there. The launch PR touched neither Rankings nor the panel, and nothing checked them.
**Decision:** The solo tables of the games outside SUELTOS are declared once, in `SOLO_TABLES` in `games.js` (game id → table), and Rankings reads them from there, showing each once its game is launched. `rankings-coverage.test.mjs` reads every game page's `avisoPartida()` calls and fails if a recorded table is neither a SUELTOS id nor in `SOLO_TABLES`. Launching a game includes its Rankings tab and its panel name, checked in its end-to-end script.
**Why:** C-21 (every game is one more game): what a game records must reach every place that shows it, without a session having to remember. A test turns "remember Rankings" into a red check.
**Consequences:** A new game that records a score fails `tests` until it is in `SOLO_TABLES` (or is a SUELTO). The panel needs no list: it names games through `gameById`, which covers `ALL_GAMES`. ¡Al toque!'s e2e script opens `/records/` and checks its tab.
